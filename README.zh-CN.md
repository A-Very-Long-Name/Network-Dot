# Network Dot · 网络状态点

[English](README.md) | **简体中文**

每个屏幕右下角的原生网络状态小点，无菜单栏或 Dock 图标。支持简体中文和 English，自动跟随系统，也可手动切换。

**[下载最新版](https://github.com/A-Very-Long-Name/Network-Dot/releases/latest)**

注意:所有代码和简介都是ChatGPT/Codex写的

## 安装

**macOS 13 Ventura 或更高版本 · Apple Silicon 和 Intel 通用版**

1. 从 Releases 下载 `Network-Dot-1.1.1-universal.dmg`。
2. 打开 DMG，把 **Network Dot** 拖入 **Applications／应用程序**。
3. 从应用程序文件夹打开，首次运行选择是否登录后自动启动。
4. 右键点击屏幕右下角小点，可查看检测详情、更改网址、切换语言或退出。

**此版本使用临时签名，尚未经过 Apple 公证。** 首次打开可能被 macOS 阻止。确认下载来源可信后，可按 [Apple 官方说明](https://support.apple.com/102445)，在“系统设置 → 隐私与安全性”中选择“仍要打开”。无需关闭 Gatekeeper。学校管理的 Mac 可能不允许此操作，届时需联系管理员。

## 状态

| 小点 | 含义 |
| --- | --- |
| 绿色 | 最近 2 秒至少一个 HTTPS 检测成功。 |
| 红色 | 网络接口断开，或 2 秒没有检测成功。 |
| 灰色 | 启动、唤醒或切换网络后的首次检测。 |

每秒只检测一个首选目标，**默认优先 Apple**。首选失败或 0.6 秒未响应时，才并行检测其余备用目标；任一成功后取消其他请求，并记住可用目标。使用备用目标期间，每分钟重试一次 Apple（或自定义列表的第一个网址）。单次请求超时 1.5 秒，各轮检测不重叠，每 0.25 秒刷新状态。正常请求量从每秒 3 次降为 1 次，约减少 67%；延迟较高或失败时会额外请求备用目标。网络接口断开或检测恢复成功时立即更新。**2 秒从上次成功响应计时，并非精确测量断网发生的时刻**；进行中的响应和系统调度会影响实际延迟。短暂延迟也可能使小点短暂变红。

彩色中心直径 8pt，黑边为 1 个物理像素，适配普通屏及 Retina。悬浮点跨桌面和全屏应用显示，切换后自动重新置顶，不激活应用。系统切换动画、锁屏及受保护系统界面中的显示无法保证。只有小点周围 16×16pt 区域接收鼠标事件。

## 检测与校园网络

| 默认 HTTPS 目标 | 预期响应 |
| --- | --- |
| `https://www.apple.com/library/test/success.html` | HTTP 200 + `<TITLE>Success</TITLE>` |
| `https://www.gstatic.com/generate_204` | HTTP 204 |
| `https://www.cloudflare.com/cdn-cgi/trace` | HTTP 200 + `ip=` |

默认选择 Apple，其连通性测试页正文仅 68 字节；gstatic 和 Cloudflare 作为备用。不使用 ICMP ping。只要任一目标通过，单个目标被学校屏蔽不会导致红灯。内置目标校验 HTTPS 证书、最终域名及预期响应，减少把认证页当作互联网的情况。**全部目标被屏蔽时，仍无法与断网区分**。绿灯不保证所有网站或服务都能使用。

自定义网址最多 5 个，一行一个 HTTPS 地址，首选目标放在第一行；同域 HTTP 2xx 即通过，不校验内容。请使用公开、无需登录的小页面，留空恢复默认。建议在实际校园网络上验证多个允许访问的外部目标。

## 隐私

不收集遥测、不读取浏览记录、不抓包、不上传文件。检测请求直接发往目标服务，对方可见公网 IP 等普通访问信息。网址、语言及首次运行选项保存在本机，不写入请求日志。应用本身无需辅助功能、录屏或管理员权限。检测需要互联网连接。

## 登录启动与卸载

右键菜单可切换“登录时启动”，也可在“系统设置 → 通用 → 登录项”中管理。首次运行由用户选择。退出不会取消下次登录启动。卸载时先关闭登录启动，退出应用，再将应用移到废纸篓。

## 构建

```sh
./scripts/test.sh
./scripts/build.sh
./scripts/package.sh
```

构建需要 Xcode Command Line Tools，无第三方依赖。通用版包含 arm64 和 x86_64。状态测试覆盖超时、恢复、接口断开、网络切换、首选单目标检测、失败切换、重复请求抑制及定期重试首选目标。实机测试环境为 Apple Silicon macOS 27.2；Intel 和较旧系统仅完成编译检查，未覆盖所有多屏与全屏配置。

如需发布经过 Apple 公证的版本，请使用自己的 Developer ID Application 证书签名，通过 `xcrun notarytool` 提交公证，并在打包前附加公证票据。本仓库不包含签名凭据。
